## 6. 无权限/无 UAC 同意路径

自动化环境无法提供可交互的 UAC 同意桌面。一次真实界面操作中：

- 辅助进程被启动，但没有管理员权限；`HelperHost` 按设计拒绝请求。
- UI 显示“操作失败 / 没有得到管理员权限，已拒绝执行。”
- 防火墙受管规则仍为 0，状态库规则为 0。
- 历史新增 1 条失败事件，来源为“桌面程序”。

截图：[uac-result-failure.png](screenshots/uac-result-failure.png)。

这验证了**没有把未完成的操作报告为成功**。但“用户在现场点击 UAC 是/否”和“UAC 辅助进程成功提权后由 UI 显示结果”的完整交互，本次自动化环境无法验证。代码对 `ERROR_CANCELLED (1223)` 有单独处理路径；真实使用需要在交互式 Windows 桌面上手动确认。
